# Sandrivier picker tracker

Bag counting per picker for the Sandrivier pear harvest (Early Light Trading, Barrydale).

- **Scanning screen** (this repo, hosted on GitHub Pages): runs in Chrome on the farm's Android phone (Blackview FORT 1), reads NFC wristbands, works offline and syncs when signal returns.
- **Backend + dashboard**: Google Sheet + Apps Script (see `apps-script/`).
- **No picker data is stored in this repository.** Names, numbers and bag counts live only in the farm's private Google Sheet.
